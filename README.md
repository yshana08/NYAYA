# ⚖️ Nyaya — AI-Powered Rights Assistant for Gig Workers

**Nyaya** is an AI-powered platform designed to help gig workers understand and resolve workplace disputes such as **payment delays, unfair penalties, account deactivation, incentive issues, and unsafe incidents**.

Instead of navigating complicated support systems alone, workers can explain their problem in **English, Hindi, or Hinglish**, and Nyaya guides them through the entire process.

## 🚀 What Nyaya Does

* 🧠 **AI Issue Classification** — Identifies the type of worker dispute.
* ❓ **Smart Questions** — Asks relevant follow-up questions based on the issue.
* ⚖️ **Rights & Guidance** — Provides clear next steps and escalation options.
* 📋 **Evidence Checklist** — Helps workers identify and organize important evidence.
* 📄 **Smart Form Filler** — Extracts useful information from provided text.
* ✍️ **Complaint Generator** — Creates a structured complaint from the case details.
* 📂 **Case Tracking** — Allows workers to track their disputes and progress.
* 💰 **Earnings Tracking** — Records pending or at-risk payments.
* 🤝 **Human Support Handoff** — Enables escalation to human/NGO/legal-aid support.
* 📊 **Impact Analytics** — Provides insights into cases and outcomes.

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript 
**Backend:** Node.js, Express.js 
**AI:** Anthropic Claude 
**Browser APIs:** Web Speech API 
**Storage:** LocalStorage + backend case store 

## 🔄 How It Works

```text

        ↓

        ↓
Case tracking & escalation
```

## 🎯 Our Goal

Nyaya aims to make **worker rights more accessible, understandable, and actionable** by turning a worker's problem into a structured path toward resolution.

> **Understand the problem. Build the case. Take action.**

## ⚠️ Disclaimer

Nyaya is a **legal information and workflow assistance tool**, not a replacement for professional legal advice or representation.
